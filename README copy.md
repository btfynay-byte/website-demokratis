# Website Cerdas Bermedia

Website tugas Pendidikan Pancasila: **Sikap Demokratis di Era Keterbukaan Informasi Digital**.

## Isi folder
- `index.html` — struktur website dan isi 5 bagian/menu.
- `style.css` — warna, layout, dan tampilan responsif.
- `script.js` — interaksi menu dan fitur ganti foto/nama 7 anggota.

## Cara menggunakan
1. Buka `index.html` di browser untuk melihat website.
2. Di bagian **Anggota Kelompok**, klik **Pilih Foto** untuk memilih foto dari HP/laptop.
3. Klik nama anggota untuk mengeditnya.
4. Perubahan nama dan foto disimpan di browser yang sedang digunakan. Penyimpanan browser bersifat lokal; perubahan itu tidak otomatis terlihat di perangkat lain atau bagi pengunjung lain.
5. Untuk mengganti isi website, edit file `index.html` dan `style.css`.

## Cara mengunggah ke GitHub Pages
1. Masuk ke GitHub dan buat repository baru, misalnya `website-demokrasi`.
2. Upload `index.html`, `style.css`, `script.js`, dan `README.md` ke root repository (bukan hanya folder ZIP).
3. Buka **Settings → Pages**.
4. Di **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main`, folder `/(root)`, lalu tekan **Save**.
6. Tunggu beberapa saat, lalu buka URL Pages yang ditampilkan GitHub.

## Penting tentang foto
Fitur pilih foto di halaman web ini menggunakan penyimpanan lokal browser. Foto yang dipilih hanya tersimpan di browser/perangkat tersebut, bukan di repository GitHub. Jika ingin foto tampil sama untuk semua pengunjung, unggah file foto ke repository (misalnya folder `images`) dan ubah nama file gambar di kode HTML/JavaScript.
